# SystemNote

A centred, quiet line in the thread for something that happened to the huddle, not something someone said.

- Text in `ink-muted` at 13px, with an optional `time`.
- Use it for: "Maya Chen started the huddle", "Huddle AI joined", "Maya Chen paused Huddle AI", "Eli resumed Huddle AI", "Eli renamed the AI to Sage", and joins.
- Keep it factual and short. No emoji, no exclamation marks.
- It's a `note` role, so screen readers announce it without interrupting.
