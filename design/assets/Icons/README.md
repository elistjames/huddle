# Icons

28 outline icons from Lucide (lucide-static 1.48.0), copied unchanged. They're used under the ISC licence; see LICENSE.txt in this folder.

- The files draw in `currentColor`. Shown as an `<img>` they render black. In product, use the `Icon` component (or inline the SVG) so they take the surrounding text colour: `ink-muted` at rest, `ink` when active, `danger` for errors.
- Product size is 20px with a 1.5px stroke. At 16px and below, use a 2px stroke.
- Icons are never amber. The AI is marked by its avatar.
- To add one, copy the exact file from Lucide. Don't redraw or edit the paths.

New in this pass: clock, pause, play and download, for receipts, agent control and export. Icons for features outside v1 (paperclip, smile, reply, trash-2, pin, bell, search, plus, user-plus, log-out, message-square, check-check, copy) stay in the set but are marked reserved in the Icon guidelines.
