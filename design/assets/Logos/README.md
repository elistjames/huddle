# Logos

The Huddle mark, drawn on a 144-unit grid: a rounded square (radius 32), a 52-unit disc and three 16-unit dots on a 24-unit pitch. It comes from the cover's amber-soft block.

- `huddle-mark.svg`: amber `#b45309` on amber-soft `#fcefd6`. For light backgrounds.
- `huddle-mark-dark.svg`: amber `#f2a33a` on `#33240c`. For dark backgrounds.
- `huddle-app-icon.svg`: amber-soft `#fcefd6` on amber `#b45309`. The app icon and favicon, and the best choice below 32px.

There's no wordmark file. In product, use the `Logo` component, which sets "huddle" in live Inter. The colours are fixed hex values that match the light-theme tokens (the dark file matches the dark theme).
